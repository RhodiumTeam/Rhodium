# 看板对外怎么开、谁来认人，由你选；Rhodium 不做登录页

这篇回答：看板经什么从手机上够得着，谁来认是不是你，以及选了“Rhodium 不认身份”时要担哪些风险。

前置阅读：[术语表](../../GLOSSARY.md)、[产品说明](../product.md)

状态：已接受（2026-10-27）。它改掉了[产品说明](../product.md) §7 原来的“不对公网开放”。

[看板](../../GLOSSARY.md)听哪个地址、谁来认人，都可以配置：

- **默认不变。** 只听本机，由 `tailscale serve` 把你的 tailnet 转进来，看板按请求头 `Tailscale-User-Login` 认你。
- **也可以交给你自己的反代。** 反代是挡在看板前面、替它收公网请求的服务，例如 Cloudflare Tunnel 加 Access、WAF。这时看板不认身份，谁连得到它的端口，谁就能用；认人全靠反代。
- **只在本机用也行。** 不认身份、只听本机，就只有本机的浏览器，或经 `ssh -L` 转过来的，打得开。

Rhodium 自己不做登录页。密码、通行密钥、客户端证书都不做。

## 为什么

- 不是每个装 Rhodium 的人都用 Tailscale。已经有 Cloudflare、WAF 这类反代的，想接自己的。
- 登录页要管密码、会话、找回和防暴力破解。这些反代都做得更好，Rhodium 不重做一遍。

## 始终保留的两道检查

不管谁来认人，这两道都在：

- **主机名白名单。** 请求的主机名必须是本机的（`127.0.0.1`、`localhost`），或你配的那几个，精确比对，不按后缀。它防 DNS 重绑定：别的网站把自己的域名解析到你的机器，借你的浏览器读看板。
- **同源检查。** 写请求和网页终端的握手，只认看板自己的页面发来的。Tailscale 的身份头和反代的登录 cookie 都是浏览器替你带上的，不查同源，别的页面就能借你的浏览器写看板、连终端。

## 考虑过的其他方案

2026-10-27 定为不做：

- **Rhodium 自己校验 Cloudflare Access 签的令牌。** 这样只能配 Cloudflare 一家。换别的反代，又要为它再写一套。
- **通用的“信任某个请求头”。** 最容易配错：反代没删掉请求里自带的同名头，或者某条路径没挂上认证，公网上谁都能自己写这个头，拿到终端。
- **通行密钥、客户端证书。** 都是 Rhodium 自己认人，等于做登录页。

## 不认身份的风险

选了不认身份，下面这些由你担：

- **谁连得到端口，谁就完全控制看板。** 包括网页终端，等于能以你的身份跑任何命令。
- **本机端口不分系统用户。** 同一台机器上的其他账号也连得到 `127.0.0.1`。多人共用的机器上不认身份，等于把你的终端交给他们。
- **信任根变成反代和它的账号。** 例如 Cloudflare 账号被盗、Access 的策略放宽了、接了一个不核实邮箱的身份源，都等于把终端交出去。账号要开两步验证。
- **反代能看到明文。** 它在自己那里解开 HTTPS，看得到对话原文、看板上不打码的工具参数、日志、你上传的文件，和终端的每次按键、每一屏。`tailscale serve` 是端到端加密的，tailnet 的中继看不到这些。
- **反代漏配，看板就对公网全开。** 例如 Access 没挂上，或者只管了部分路径。所以 `rh doctor` 每天不带登录访问一次你配的每个主机名，能直接打开看板就报错。
- **请求里带的 `Tailscale-User-Login` 不看。** 这不算漏洞：本来就不认身份，看它也挡不住什么。

Tailscale 模式也有一条：端口前不能再接把主机名改成本机地址的代理，例如 nginx 的默认写法。接了，公网上谁都能自己写 `Tailscale-User-Login` 冒充你。所以 Tailscale 模式只认 tailnet 和本机的主机名，再配别的算配置写错。

## 后果

- 产品说明 §7 改为：默认只在 tailnet 上；你也可以经自己的反代开放，风险自己担。
- 看板不打码的理由改为：看板只给你看。你选的反代能看到明文，算在这个选择里。
- 页面为反代的登录过期做两件事：装到手机桌面时的清单文件带上 cookie 去取；请求说明自己是页面发的，收到 401 就整页刷新，转去反代的登录。
- 网页终端空闲时，看板定时 ping 页面，免得反代断掉空闲的连接。
- 配置写错只关看板，不挡 Rhodium 启动。IM 和 `rh` 照常。
- 看板还是只听一个端口、只用一种认法。同时开两种（例如 tailnet 和 Cloudflare 一起）不做：Cloudflare 不删请求里自带的 `Tailscale-User-Login`，公网上谁都能冒充你。
