这篇用到几个词：

- 工作区标题：首页列表里工作区卡片上那行小字（点了折叠），和放大模式侧栏里工作区的标签。
- 单独一行的槽位：所在工作区在列表里没有标题、按全名单独一行显示的槽位（[产品说明](../product.md) §7 首页的排法）。
- 导入列表：导入弹窗里，选了 agent 以后列出的会话。
- 信息行：目录选择器路径框下面那一行。
- [小弹窗](../../GLOSSARY.md)：点按钮在它旁边弹出的小框，见术语表。

## 问题

**新建和导入绕。**

- 只有首页的“+”、放大模式侧栏顶上、拓扑图工作区详情三个入口，都从底部升起一张单子。宽屏上它横在整页底部。
- 人已经在某个工作区里，新建还是要过一遍目录选择器；导入要先选文件夹，再按“列出”，再从几个 agent 混在一起的列表里挑。
- 选择器上一排工作区按钮、一行文件名，占地方又不常用。

**导入列表看不出是哪段。**

- 每行写目录、时间和开头八个字。分不出哪段是你要的，也搜不了。
- 只列最近 10 段，再早的就找不到。
- 没说过话的空会话也列出来。

**列表行的菜单缺两处。**

- 工作区只有一个槽位时，列表里没有它的标题，就没有地方在这个工作区里新建、导入。
- 右键或长按弹出菜单时，那一行不显示选中，看不出菜单是给哪一行的。
- 在终端里的槽位一项菜单都没有：改名、收回终端、置顶都要进对话。

**终端模式的槽位看不出在说什么。**

- 列表第二行写“TUI 模式（pane …）”，不是最近一句话。

**输入框记不住发过的话。**

- 想把上一条改一下再发，要自己翻上去复制。

**上下文和额度要专门去查。**

- 要打 `/context`、`/usage` 才知道，而且会把没在跑的 agent 拉起来。
- 结果从底部升起一张卡片，盖住半屏对话。

## 方案

- 新建和导入用一个弹窗：宽屏在中间，手机从底部。从工作区进来不用选目录；从顶上的入口进来，上面是目录选择器。
- 导入先选 agent，再列出它在这个目录里的会话，每行两行字，选中就地展开最后两句。能按标题或全文搜。
- 单独一行的槽位的菜单多出“新建槽位”“导入”；在终端里的槽位也有菜单。
- 终端模式的槽位在列表里照常写最近一句话，前面一个终端图标。
- 电脑上 ↑↓ 翻发过的话。
- 输入框的按钮行常驻上下文圆环，宽屏上还有额度细条。数字是 Rhodium 记下的最近一次，只在 agent 本来就在跑时更新。点开是小弹窗，`/usage`、`/context`、`/model` 也都改成小弹窗。

宽屏，侧栏里工作区标题上的两个按钮（鼠标移到标题上才显示）：

```
▾ atlas                       ⊕  ⇣     ← 新建槽位、导入
  ✳ 搜索重构                    刚刚
  ✳ 索引性能                  10分钟前
```

从工作区导入，宽屏在屏幕中间：

```
┌ 导入 ───────────────────────────────────┐
│ ▢ atlas  ~/projects/atlas                │
│ [✳] [pi] [codex]                         │  ← 先选 agent
│ [搜索                  ] ☐ 开启全文搜索  │
│ 把 CI 的缓存挪到 actions/cache v4        │
│ ▣ 在 Herdr 里开着                        │  ← 开着的排最前
│ 修复登录页窄屏按钮换行                 ✓ │  ← 选中，就地展开
│ 12分钟前  ▢ 38  ⎇ fix/login-narrow      │
│              再看一下 iPhone SE 的宽度…  │  ← 你最后说的话
│ 在 320px 下量了一遍：两个按钮现在各占…   │  ← agent 最后回复的开头
│ 解释一下这个正则……                       │
│ 2小时前  ▢ 6                             │
│ [修复登录页窄屏按钮         ]            │  ← 名字，用标题预填
│ [            导入            ]           │
└──────────────────────────────────────────┘
```

顶上的“导入”多一个目录选择器，信息行改成：

```
│ ⌂ [~/projects/atlas/                ] ↑ │
│ ⎇ feat/search  ±3  ↑2 ↓1   ✳ 12 3小时前  pi 2 昨天 │
```

宽屏的按钮行：

```
│ [✳] [opus high v] [>_]        [+] ━ ━ ━  ◔ 42%  [↑] │
                                     ↑ 额度细条，一个窗口一条；◔ 上下文圆环
```

## 用户故事

“用户”就是你本人。编号接着前面几篇规格，从 634 开始。每条写明哪张工单做（见“拆工单”）。

### 导入列表和搜索（第 2 张）

641. 作为用户，我想要导入时先选 agent，再列出这个 agent 在这个目录本身（不含子目录）的会话，Herdr 里开着的排最前，以便列表里只有我要找的那种。换掉故事 321、542 里的“列出”按钮：选好 agent 就列。
642. 作为用户，我想要每段会话排两行：第一行是标题，有 `/rename` 起的名字或 agent 自动起的标题就用它，没有就用我的第一句话；第二行是最后活动时间、消息条数、git 分支，以便认出是哪段。
643. 作为用户，我想要选中一行就地展开我最后说的话和 agent 最后回复的开头三行左右，以便确认是这一段再导入。
644. 作为用户，我想要没有消息的会话不列，以便列表里都是真聊过的。
645. 作为用户，我想要先显示 10 段，往下滚再加载，以便很早的会话也找得到。
646. 作为用户，我想要导入时的名字用标题的前十来个字预填，可以改，以便不用自己想名字。
647. 作为用户，我想要列表上方有搜索框和“开启全文搜索”复选框：不勾只搜标题，勾上还搜我说的话和 agent 回复的正文；工具输出、思考过程、图片和元数据始终不参与匹配，以便按记得的一句话找到会话。

649. 作为用户，我想要从工作区进来只搜这个工作区的目录；从顶上的导入搜所有目录，选中一段后目录选择器跳到它的目录，以便忘了在哪个项目里聊的也找得到。

### 输入历史（第 3 张）

650. 作为用户，我想要电脑上光标在输入框第一行时按 ↑ 翻出我在这个槽位发过的话，一直往前翻；光标在最后一行时按 ↓ 往回翻，翻过最新一条回到原来的草稿，以便像终端和 Claude Code 一样改一下上一条再发。
651. 作为用户，我想要历史按槽位分开，只算我在这个槽位里说的话，网页和 IM 发的都算，别的槽位发来的和汇报不算；手机上不做，以便翻出来的都是自己的话。

## 实现决定

### 弹窗（第 1 张）

- 宽屏（和中屏）上是屏幕中间的对话框，盖一层半透明的底，最宽 32rem。手机上照旧是底部的单子。同一个组件按宽度换外壳，里面一样。
- 从工作区进来的：
  - 弹窗顶上一行：文件夹图标、工作区名、灰色等宽的目录。没有目录选择器。
  - 新建：名字框和 agent 的一排 logo 在同一行，下面“新建”。名字预填“工作区名-n”，n 取不和这个工作区里任何槽位（含已归档的）重名的最小正整数。工作区名太长时把它截短，让整个名字不超过 64 个字。发 `rh new <工作区>/<名字> --agent <agent>`，和原来一样。
  - 导入：agent 的一排 logo，下面是导入列表（第 2 张），最下面名字框和“导入”。
- 从顶上进来的（侧栏的“新建槽位”“导入”、首页的“+”、拓扑图工作区详情的“新槽位”）：
  - 弹窗上面是目录选择器，下面同上。拓扑图工作区详情和侧栏的从那个工作区的目录开始，首页的“+”从 `~` 开始（故事 540 照旧）。
  - 选择器去掉一排工作区按钮和一行文件名，别的照旧（[网页能写规格](web-write.md#目录选择器)）。
  - 文件夹不是哪个工作区的默认目录时，信息行下面照旧有新工作区的名字框，能改。这一处没在拷问里问，照旧留着：新建要用它。
- 工作区标题上的两个图标：首页列表的工作区卡片标题和侧栏的工作区标签都有，在标题这一行的最右。宽屏上鼠标在这一行上才显示，键盘聚焦到它们时也显示；手机（`pointer: coarse`）上一直显示。点它们不折叠工作区。
- 拓扑图的工作区详情照旧只有“新槽位”，不加导入。

### 信息行（git 第 1 张，会话数第 2 张）

- 一行图标加数，不带字，放不下时横着滚：
  - 分支。不在分支上时不写。
  - 没提交的文件数，大于 0 才写。
  - 比上游领先、落后几个提交，各自大于 0 才写；没有上游不写。
  - 每种 agent 一项：logo、会话数、最近一段的时间（写法同列表的时间）。没有会话的 agent 不写。
- 数据来自 `GET /api/folder`，见[架构](../architecture.md) §7.10。会话数和导入列表同一个口径：至少有一条消息、槽位没用过的。第 2 张合进来之前，`/api/folder` 只回 git 的几项。选择器停在一个文件夹 300 毫秒以后才取，路径框边打边补全时不取。
- 取不到 git 的部分（不是仓库、超时）只少那几项，别的照写。

### 列表行的菜单（第 1、5 张）

### 输入历史（第 3 张）

- 只在电脑上（`pointer: fine`）。
