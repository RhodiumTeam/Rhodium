这篇用到几个词：

- 宽屏：至少 1024px 宽，和现在的分栏、拓扑图同一条线。
- 中屏：600–1023px 宽，而且至少 480px 高（2026-10-28 定），例如折叠屏展开。横着拿的手机高不到 480，还算手机。
- 分栏：宽屏上左边是列表或拓扑图、右边是对话的样子。左边默认占 40%。
- [放大模式](../../GLOSSARY.md)：对话顶栏点“放大”以后的样子，见术语表。
- 侧栏：放大模式左边那条窄栏。
- 来处：放大模式是从列表旁边的对话进来的，还是从拓扑图旁边的对话进来的。
- [跳转框](../../GLOSSARY.md)：按 ⌘K 弹出、按名字找槽位的框，见术语表。
- 两行排法：列表里一个槽位排两行，最近一句话在第二行。手机上就是这样。
- 一行排法：最近一句话排在名字同一行的右边。列表按自己的宽度换，40rem（640px）起是一行排法。
- 落点：一个聊天窗口现在的话交给哪个槽位，见[网页拓扑图规格](web-topology.md)开头。
- 闪一下：`/rh_ls` 在宽屏上让列表里当前那一行闪的那一下（[查询命令规格](info-commands.md)）。

## 问题

**“放大”是坏的。**

- 按了以后，左边 40% 变成一块空白，对话原地不动，也不变宽。
- 根因：左栏是用 `display: none` 藏的，只藏住了里面那层，外层参与分栏的那层还占着 40%。

**放大了也没多出什么。**

- 对话正文连边距最宽 768px。屏宽 1280px 起，分栏里的对话那一栏已经比这宽，正文早就到顶了。
- 放大以后要换槽位，得先还原再点，两步。拓扑图那边要两到四步。

**左栏拖窄了就不能用。**

- 拖到最窄（20%）时，看板顶栏被截掉，名字被挤成“open-so…”。
- 合在一起的卡片里，工作区那半被挤得只剩一个字母，看着像“Hhomehelp”。

**列表看不出在 IM 里回话会进哪。**

- 哪个窗口落在哪个槽位，只有拓扑图上画着。

**换槽位只能用鼠标。**

- 没有按名字找槽位的地方，也没有换上一个、下一个的快捷键。
- 几个 agent 一起跑时，行会在鼠标底下换位置，一点就点错。

**拓扑图按钮两处不一样。**

- 宽屏上，对话顶栏的拓扑图按钮会关掉对话，看板顶栏的“拓扑图”却不会。

## 方案

- **平时不变。** 宽屏上照旧是分栏。只顺手修两处：对话顶栏的拓扑图按钮不再关掉对话；左栏最窄改成 360px（后来是 370px，见下）。
- **“放大”修好，进放大模式。**
  - 左边的列表或拓扑图换成一条专门的窄侧栏，默认 288px；对话往左拉到侧栏边上。
  - 地址照旧加 `full`，算一步。按返回回到分栏。
  - 放大模式里拖线、改窗口，左边都还是侧栏。只有点“缩小”才回分栏。
  - 缩小回去，列表或拓扑图落在最后打开的那个槽位上。
- **侧栏：**
  - 没有标题。最上面三个按钮：新建槽位、跳转、导入。往下滚过一截，收成并排的三个图标，和对话顶栏一样高；滚回最上面才展开。收起展开时，没有一行跟着挪。收着时鼠标停在空白处、或者点空白处，临时展开，盖在行上（2026-10-28 加）。
  - 下面是需要你的、能折叠的工作区标签、已归档。行不装卡片。滚到哪个工作区里，它的标签就冻结在顶上。
  - 能收起到 0 宽，展开按钮上亮琥珀点。窗口窄于 1280px 时默认收着。
  - 左下角固定一个齿轮，点开切主题、开关跑完提醒（2026-10-31 加）。
- **Bot 头像：** 首页列表、分栏里的列表、侧栏，都在槽位名右边画你现在在 IM 里说话会进这里的 Bot。
- **键盘：** ⌘K 跳转框；Alt+↑↓ 换上一个、下一个；⌘B 收起、展开侧栏；电脑上打开槽位，光标就在输入框里。
- **真全屏：** 对话的“⋯”里加“全屏”。
- **中屏：** 打开对话直接进放大模式，侧栏默认收着，没有分栏（2026-10-28 定）。
- **手机：** 首页列表多了 Bot 头像、折起的工作区的蓝点，名字里工作区那半至少留 3 个字。别的不变。中屏的首页列表也一样。

### 这些没单独问，直接定了

### 平时的分栏

- 不变的：左边默认 40%，中间的线能拖；分栏宽度照旧记在这个标签页里。
- 顺手修两处：
  - **对话顶栏的拓扑图按钮，宽屏上不再关掉对话。** 左边换成拓扑图，对话留着，地址是 `#/topology/slot/<槽位 ID>?chat`，替换当前这一步。和看板顶栏的“拓扑图”一样。手机上照旧。
  - **左栏最窄从 20% 改成 22.5rem（360px）。** 360px 是最窄的手机，列表和看板顶栏都按它设计。
    - 2026-11-10 起最窄 370px：电脑上列表给滚动条留 10px（#635），去掉这 10px，左栏里面还是 360px 宽。

### 放大模式

进来：

- 按钮还在对话顶栏右边原来的位置，lucide `Maximize2`。
- 点了以后，左边的列表或拓扑图换成侧栏，对话那一栏的左边拉到侧栏边上。侧栏收着时，对话占满整页。
- 同一个位置换成“缩小”（`Minimize2`）。读屏标签是“放大”“缩小”，原来的“还原”改叫“缩小”。
- 对话不重画。#285 对正在写的那段的保证照旧，放大、缩小、收起、展开都算在里面。
- 左栏不再用 `display: none` 藏，换内容、换宽度。
- 手机和中屏没有这个按钮。中屏打开对话就是放大模式，见[中屏怎么做](#中屏怎么做)。

地址记着来处：

| 从哪放大 | 放大模式的地址 | 缩小回到 |
|---|---|---|
| 列表旁边的对话 | `#/slot/<槽位 ID>?full` | `#/slot/<槽位 ID>` |
| 拓扑图旁边的对话 | `#/topology/slot/<槽位 ID>?chat&full` | `#/topology/slot/<槽位 ID>?chat` |

每种操作对地址和历史的影响：

| 操作 | 地址 | 历史 |
|---|---|---|
| 点放大 | 加 `full` | 新加一步 |
| 点侧栏一行、在跳转框里选一个 | 换成那个槽位，保留 `full` 和来处 | 新加一步 |
| Alt+↑↓ | 同上 | 替换当前这一步 |
| 收起、展开侧栏，拖宽度 | 不变 | 不算一步 |
| 点缩小 | 去掉 `full` | 刚放大、还没换过槽位：等于返回一步。换过：替换当前这一步。点行、跳转框、Alt+↑↓ 都算换过，Alt+↑↓ 虽然只替换这一步，也要去掉“刚放大”的记号 |
| 按返回 | 回到上一步：放大模式里看过的上一个槽位，或者放大前的分栏 | |

- 刷新还是放大模式。侧栏收没收起，照这台设备记住的来。
- 以前带 `full` 的地址和书签，打开就是放大模式。
- 手机打开带 `full` 的地址：照旧是单栏的对话。中屏打开是放大模式。窗口拉宽到 1024px 以上，也是放大模式。

宽度和改窗口：

- 中间的线只调侧栏的宽度：16rem 到 28rem（256 到 448px），默认 18rem（288px）。
- 往左拖过最窄，侧栏收起。双击中间的线，回到 18rem。
- 改窗口大小时，侧栏的像素宽度不变，变的是对话那一栏。
- 但对话那一栏至少留 360px，和最窄的手机一样：画的时候侧栏最宽取 448px 和窗口宽减 360px 里小的那个，拖也拖不过它。这个数小于 256px 时（窗口 600–615px 宽），侧栏照样画 256px，对话那一栏就少于 360px。存着的宽度不改，窗口拉宽回来照旧。
- 窗口窄到 1024px 以下：中屏还是放大模式；再窄成手机，变成单栏，只剩对话，和手机一样。拉宽回来还是放大模式。
- 侧栏宽度存在这台设备的 `localStorage`，只记一份：从列表、从拓扑图进来用的是同一条侧栏。读写都包在 try 里，取不到就用默认。

收起侧栏：

- 按钮在对话顶栏最左边，放大模式里顶替“‹”。侧栏开着时是“收起侧栏”（`PanelLeftClose`），收着时是“展开侧栏”（`PanelLeftOpen`）。
  - 放大模式里“‹”是回首页、关掉对话，很少用。要出去点缩小，要换槽位点侧栏。
- 快捷键 ⌘B（Mac）或 Ctrl+B，只在放大模式里接，输入框里也接。
- 收起就是 0 宽，什么都不留。里面的东西不画，Tab 键走不进去。
- 收起、展开是 150ms 的滑动：侧栏按自己的宽度排好，整条从左边滑进滑出，字不跟着重排。收起时行和中间的线留到滑完才藏，不会先剩一片空白。系统设了“减少动画”就不滑。
- 琥珀点：收着时，当前这个以外还有槽位需要你，展开按钮右上角亮一个琥珀色小点，不写数字。点和图标的线隔开，不压在线上。
- 收没收起，这台设备记住，窗口 1280px 以上和以下各记一份。
  - 从没动过时，窄于 1280px 收着，1280px 起开着。
  - 只在进放大模式和刷新时读。页面开着时拖窗口跨过 1280px，侧栏不会自己收起或展开。
- 不改地址，不算一步。

缩小，落在哪：

- 回到进来时的分栏，分栏宽度是这个标签页记着的。
- 列表：最后打开的那个槽位就是当前的，它那一行有底色。滚到看得见的地方，闪一下。它在折起的工作区里或者在“已归档”里，也露出它那一行（故事 435）。
- 拓扑图：地址就是 `#/topology/slot/<最后那个槽位>?chat`。拓扑图照现有的规则把地址里的槽位当焦点，镜头不沿用放大前的，按新焦点重新对准。
- 键盘焦点留在对话里。

从拓扑图进来：

- 侧栏里的行记着来处：点了以后换槽位，地址还是 `#/topology/slot/<新槽位>?chat&full`。
- 从列表进来的放大模式，顶栏照旧有拓扑图按钮。点了离开放大模式，到拓扑图加对话，落在当前槽位上，替换当前这一步。
- 从拓扑图进来的没有这个按钮，和现在一样。要回拓扑图，点缩小。

`/rh_ls`：

- 放大模式里打 `/rh_ls`，留在放大模式。侧栏收着时先展开，再闪一下当前那行。
- 分栏和手机上照旧（[查询命令规格](info-commands.md)）。

### 中屏怎么做

2026-10-28 定的（#452）。中屏就是宽屏去掉分栏：只有放大模式。

- 判断：视口 600–1023px 宽，而且至少 480px 高。和宽屏的判断放在一处，不再在六个文件里各写一份。
- 打开槽位的对话，直接进放大模式。列表的行、拓扑图的“打开槽位”、跳转框、跑完提醒都算。
  - 地址和宽屏分栏时一样：从列表是 `#/slot/<槽位 ID>`，从拓扑图是 `#/topology/slot/<槽位 ID>?chat`。中屏上这两种不带 `full` 也是放大模式，带了也一样。
  - 新加一步，和手机上打开对话页一样。
  - 侧栏收没收起，照 1280px 以下记的那份；从没动过就收着。
- 放大模式的别的都照旧：侧栏、⌘B、Alt+↑↓、焦点、“⋯”里的“全屏”。没有“放大”按钮，没有分栏可放大。
- “缩小”留着，同一个位置，回到对话的来处：
  - 从列表来的，回首页列表，那一行闪一下。
  - 从拓扑图来的，回拓扑图，焦点落在最后打开的那个槽位。
  - 刚打开、还没换过槽位：等于返回一步。换过：替换当前这一步。和宽屏上缩小同一条规矩。
- 对话顶栏的拓扑图按钮照手机：打开 `#/topology/slot/<槽位 ID>`，新加一步。
- 拓扑图照手机的排法：底部的详情、手机的节点大小。只有“打开槽位”不同，进放大模式的对话。
- 窗口拉宽过 1024px：同一个地址，不带 `full` 是分栏，带了是放大模式。窄到 600px 以下或矮到 480px 以下：成了手机的对话页；拓扑图那边带 `?chat` 的地址在手机上只画拓扑图，和现在一样。
- 手机、1024px 以上都不变。

### 侧栏

| 按钮 | 做什么 |
|---|---|
| 新建槽位 | 打开新建槽位的单子，目录选择器从当前对话的工作区的目录开始（2026-10-28 改，原来是预选这个工作区） |

| 导入 | 打开导入的单子，和首页“+”里的一样 |

- 单子就是[网页能写规格](web-write.md#新建和导入)里那两张。建好、导入好，按回复里的 `slot` 在放大模式里打开，来处不变。
- 三个按钮固定在侧栏顶上，盖在列表上面，和列表在同一个滚动区里。列表最上面留出三个按钮展开时的整块高度，所以按钮收起、展开时，没有一行跟着挪。
- 侧栏里没有看板顶栏：没有“Rhodium”和色点、没有“列表”“拓扑图”切换、没有顶栏的 `+` 和齿轮。断线时对话顶栏会写“已断开”。主题在左下角的[设置](#设置)里。

往下滚时收成图标：

- 三行 128px，一行 57px。一行和对话顶栏一样高，两边的下沿连成一条线。收起多出约 71px，约一个半槽位。
- 滚过约 87px，三个按钮收成一行：三个图标并排靠左，不带字。87px 是收起腾出的 71px 再多一点，收完时眼前露出的是行，不是顶上那块空白。
- 只在滚回最上面（滚动位置 0）时展开成三行。收着时来回滚都不展开，所以不会时收时放；展开时盖住的只有顶上那块空白，不盖住看得见的行。
- 收着时能临时展开（2026-10-28 定，#456）：
  - 鼠标在这一行的空白处停约 300ms，展开成三行。鼠标离开这一块约 1 秒后收回。
  - 空白处只算最宽的按钮展开后够不着的地方，在它右边。
  - 停在图标上、图标之间或图标下面那条缝上，都不展开：展开会把别的按钮挪到指针底下。
  - 触屏上点空白处，展开；再点空白处，收回。
  - 临时展开时，三个按钮按内容宽度画，不撑满整行。这样原来点的空白处展开后还是空白，再点一次能收回。撑满的话，同一个位置会落在“新建槽位”或“跳转”上。
  - 滚动，或者按了其中一个按钮，马上收回。
  - 临时展开时盖在行上面，没有一行跟着挪。冻结的标签、滚动留白、“↑ 需要你”都照收着时的算。
- 能滚的列表都能收：滚不到 87px 的，列表末尾补一段空白，补到能滚过 87px。一点都不用滚的列表不补，也不收，一直是三行。
- 收成一行还是那三个按钮：读屏标签照旧是“新建槽位”“跳转”“导入”；鼠标停住提示这几个字，跳转的提示带快捷键。焦点在其中一个上时，收起展开都留在它上面。
- 收起展开约 200ms：收起时字先淡出，按钮再挪成一行；展开时按钮先挪回去，字再淡入。系统设了“减少动画”就不动画。

需要你的滚出去以后：

- 需要你的行都滚到顶上那一块下面、一行都看不到了，顶上那一块第一行的右边出一个琥珀色的“↑ 需要你”，点了滚回最上面。
  - 按钮还带着字时也出，压在“新建槽位”那一行的右端：需要你的往往在按钮收起之前就滚出去了。
  - 收成一行时，它在三个图标右边。
- 还看得见一行需要你的，就不出。
- 为什么：需要你的排在最上面，就是要你一眼看到；侧栏开着时又没有琥珀点。不把需要你的钉在顶上：有五六个时钉住的一块太高。

工作区标签冻结：

- 滚到一个工作区里，也就是它的标签滚到顶上那一块的下沿、下面还有它的行时，标签停在顶上那一块下面，行从它下面滚过去。顶上那一块收起、展开时，冻结的标签跟着上下挪。
- 下一个工作区的标签滚上来，把它往上顶走，换成下一个冻结。
- 需要你的、合在一起的那组没有标签，滚到它们里面时什么都不冻结。
- “已归档”展开着时，滚进去也一样冻结它的标签。
- 冻结的标签底色和侧栏一样，不透出下面的行。
- 点冻结着的标签，照样折起这个工作区。折起以后它留在原处，下面紧接着下一个工作区。后面剩下的不够一屏时，列表滚到底。

列什么、怎么排：

- 同一份数据、同一个排法，就是首页列表的（`web/src/board.tsx` 的 `layout()`，[产品说明](../product.md) §7）。
- 不装卡片：
  - 需要你的：在最上面，名字写全（带工作区），右边是琥珀色的“需要你”。不加标题。
  - 工作区：一行标签。左边是折叠箭头，然后是名字。折着时右边写槽位数，里面有在跑的，数字前加蓝点。
  - 工作区下面的槽位：比工作区标签缩进一点，只写槽位自己的名字。子槽位再往里缩。
  - 合在一起的那组：和工作区标签对齐，名字写全，例如 `Hom…/homehelp`。2026-10-31 起这样的组可能有几段，夹在工作区标签之间（#506）。
  - 置顶的：在需要你的下面，上面一行只有一个图钉，和工作区标签一样高，读屏念“置顶”。不折叠，也不冻结。行和合在一起的那组对齐，名字写全（#506）。
    - 下面有别的行或已归档时，置顶以一条横线收尾，和顶上按钮下面的那条一样。不然紧跟着的合在一起的那组没有标题，看着也像置顶的。
  - 已归档：最底下“› 已归档 N”，默认折着。行照旧带恢复按钮，不写时间。
- 行，默认宽度下是紧凑的两行：
  - 第一行：logo 加状态点，名字，Bot 头像，最右边是状态。
  - 第二行：最近一句话。运行中却没在跑回合的（等额度、TUI 模式、启动中），这一行换成蓝字的状态，和首页一样。
  - logo 28px，子槽位的 22px；子槽位每层多缩进 16px；完成的写“3分钟前”，不写“3分钟前结束”。
  - 侧栏拖宽过 20.5rem，行变成手机上的两行，logo 大一号，还是不装卡片。按拖到的宽度换，不按展开动画里的宽度，所以进放大模式时行不会先大后小。
  - 换了排法行变高时，当前那行还留在看得见的地方。
- 名字放不下时，工作区那半先缩，至少留 3 个字，例如 `Hom…/homehelp`。首页也一样。“…”紧贴着“/”，中间不留空。
- 侧栏里没有搜索框。未读见[未读和跑完提醒怎么做](#未读和跑完提醒怎么做)。

折叠和滚动：

- 工作区折没折，和首页共用，记在这台设备上。“已归档”开没开，和首页共用，照旧只在页面开着时记着。
- 需要你的从不放在工作区里，所以折起工作区不会藏掉要你的。
- 点侧栏里的一行换槽位时，侧栏不滚动。
- 进放大模式时侧栏从最上面算起。当前那行和需要你的放得下就都看得到；放不下，当前那行滚到最底下刚好看得见。
- Alt+↑↓、跳转框换过去时，当前那行只滚到刚好看得见，不藏在顶上那一块和冻结的标签下面。
- 焦点在侧栏里按 PageDown、空格、PageUp 翻页，也一样：翻过去以后，上一页边上的行不会落到顶上那一块和冻结的标签下面。一页里只有折起的工作区标签时，照浏览器自己的翻页。
- 滚动条：
  - 电脑上（`pointer: fine`），看板的滚动条一律不带箭头（#630，2026-11-09 定）。整页的（首页和分栏左边的列表、对话）和框里的，都是看板自己那种细的圆角滚动条，和命令面板、跳转框的一样。
  - 手机上照旧：整页的滚动条是浏览器自己那种细的，浮在字上、不占地方。
  - 颜色用界面自己的淡灰，轨道透明。
  - 侧栏的滚动条平时不显示，鼠标在侧栏上或焦点在侧栏里时才显示。

### 列表的排法和置顶怎么做

2026-10-31 定的（#506）。排法见[产品说明](../product.md) §7。

服务器：

- 槽位表加两列：`activeAt` 是最近的[动静](../../GLOSSARY.md)，`pinnedAt` 是置顶的时间，没置顶是空的。
- 路由在这几处写 `activeAt`：回合开始、回合结束（停掉的也是）、新建槽位、从归档恢复（`rh unarchive`、你的消息或命令、`rh send`、给 Bot 设默认目标，五处都写）。
- 升级时补上：在跑的取本回合开始的时间，别的取最近一个回合结束的时间，都没有的留空。
- `/api/board` 的每个槽位带 `activeAt` 和 `pinnedAt`。没有回合在跑的（TUI 模式的都算），`activeAt` 取它、回合结束、最近一句话里最晚的那个：TUI 模式拿不到回合的开始和结束，在终端里说的话切回无头以后也要算，升级前在终端里用过的也一样。回合在跑时不看最近一句话，回合中途的话不算。
- “刚结束”固定 24 小时，不再借 `durations.oneoffArchive`。
- 置顶是一种新的写请求：`{ kind: "pin", slot, on }`，回“已置顶 w/x。”“已取消置顶 w/x。”。不加 `rh` 命令，IM 不变。

网页：

- 网页只按 `activeAt` 排，排法在 `layout()` 一处，首页和侧栏共用。
- 每行先找它所在的树的根，一路往上经过的槽位里有置顶的，这棵树进置顶，按最上面那个置顶的槽位的时间排。
- 别的行按根分块：根的工作区有两个以上顶层槽位，进这个工作区的块；不然这棵树自成一块。顶层槽位指父槽位不在用的槽位，需要你和置顶的也算，所以一行挪走时工作区的卡片不散。
- 块里照旧用 `tree()` 排成树，只是排序的键换成动静。
- 触屏：`useHeld` 接 `touchstart`，抬起最后一根手指 3 秒后放开。不看手指的 `pointerleave`：抬起和滚动时它马上就来。

这些没单独问，直接定了：

| 定了什么 | 为什么 |
|---|---|
| 需要你那组里照旧按最近一句话排 | 那组要看的是谁刚问 |
| 空闲的时间改写动静的时间，不写最近一句话的时间 | 和顺序对得上；刚恢复、刚导入的不会排在上面却写着三天前 |
| 父槽位置顶又需要你时，子槽位留在置顶里单独一行 | 和“父槽位需要你时子槽位留在原处”一样 |
| 菜单里“置顶”排在“停止”后面、“开新对话”前面 | 别家的会话菜单都把置顶放在最上面 |
| 置顶后鼠标还在列表上时，行等鼠标移开再挪；轻提示说已置顶 | 和别的重排一样，不在鼠标底下挪行 |
| 置顶那一组上面只有一个图钉，读屏念“置顶” | 字少；和需要你那组一样不写标题 |

### Bot 头像

画哪些：

- 画你现在在 IM 里说话会进这个槽位的那些 Bot：你和这个 Bot 的私聊，或者主窗口，落点是这个槽位，就画这个 Bot。
  - 落点用路由同一份 `target()` 算，和拓扑图的绑定是同一份：跟着 Bot 默认目标的窗口算，单独选过这个槽位（`/rh_use`）的窗口也算。
  - 一个 Bot 有几个窗口落在同一个槽位，只画一次。
  - 陌生人的窗口不算，哪怕单独选过。
- 没有窗口跟着的默认目标不画。拓扑图照旧画 Bot 到默认目标的线，要看默认目标去那里看。
- 为什么按落点：真实数据里，telegram 这个 Bot 的默认目标是 dispatcher/main，可你的 Telegram 私聊单独选了 dispatcher/DeepSeek。按默认目标画，main 那行会挂着 Telegram 的头像，你在 Telegram 里说话进的却是 DeepSeek。

样子：

- 就是拓扑图里的那个头像（`web/src/faces.tsx` 的 `Face`）：Bot 头像，右下角是平台标志。没有头像时，平台标志放大顶替。
- 放在槽位名右边，紧跟着名字，不推到最右。状态照旧在最右边。
- 大小看排法：

| 排法 | 用在哪 | 头像 | 平台标志 |
|---|---|---|---|
| 两行 | 手机；1440 宽分栏里的列表；侧栏 | 18px，和名字一样高，行不变高 | 10px |
| 一行 | 平板竖屏；电脑上的首页；1920 宽分栏里的列表 | 24px | 14px |

- 几个 Bot 并排，中间隔 4px，不叠。顺序和拓扑图左边 Bot 的顺序一样。最多画 3 个，再多写“+N”。
- 地方不够时，名字先让，头像后让：
  1. 工作区那半先缩，至少留 3 个字。
  2. 槽位名再缩，至少留约 6 个字母（4 个汉字），例如 `web-te…`。7 个字以内的名字不缩。
  3. 还不够，头像少画几个，后面的“+N”跟着变大，例如一个头像加“+3”。
  4. 最窄时一个头像都不画；“+N”也放不下就什么都不画。只在侧栏拖到最窄、名字又长、右边还有“需要你”时才会这样。
- 一行排法里，名字那一格是 250px，再加上这份列表里头像最多的那一行的头像宽度。每行加的一样多，所以最近一句话那一列还是对齐的。
- 头像有一圈细边，暗色模式下深色的头像也看得出轮廓。平台标志外面那圈是行的底色，不是白色。
- 侧栏的紧凑两行里，平台标志往上挪一点，不压到第二行的字。
- 不画连接状态（重连中、故障），那在拓扑图上看。
- 头像不能单独点，点了就是点这一行。鼠标停住提示 Bot 名，读屏也念 Bot 名。
- 已归档的行，有你的窗口落在这里，也照画。

数据：

| 路径 | 变化 |
|---|---|
| `/api/board` | 加顶层的 `bots`：每个 Bot 的 ID、名字、平台、头像地址，和 `/api/topology` 给的一样。每个槽位加 `bots`：落在这里的 Bot 的 ID |

- 服务端用拓扑图现成的那份绑定（`src/board.ts` 的 `topologyRows`），只留你的私聊和主窗口，不另算落点。

### 跳转框

```
┌────────────────────────────────────────────────────────────────┐
│ ⌕ de                                                           │
│▌✳• Rhodium/dev                                         运行中  │
│ ✳• dispatcher/DeepSeek                               22分钟前  │
│ ✳  Rhodium/performance                                  3天前  │
└────────────────────────────────────────────────────────────────┘
```

- ⌘K（别的系统 Ctrl+K）开关跳转框，所有页面都能用。侧栏的“跳转”按钮也开它。
- 浮在对话那一栏上面；没开对话时，浮在页面中间偏上。
- 什么都不打时：先列这个标签页里最近打开过的，新的在前，不列当前这个；然后是其余在用的槽位，按列表的顺序。不列已归档的。所以 ⌘K 再回车，就是回到上一个。
- 打字时：名字开头对上的排前面，名字或工作区里有的其次，最近一句话里有的最后。已归档的也列，淡一些，排在最后。
- 一行：logo 加状态点，名字写全，右边是状态。不画 Bot 头像。
- ↑↓ 选，到头绕回去；回车打开；Esc、点框外面、再按一次 ⌘K 都是关掉。
- 槽位多到放不下时竖着滚，和命令面板一样（#579）：
  - 滚动条没有箭头，不被框的圆角切掉。
  - 还能往哪头滚，哪头渐隐；↑↓ 选到的那行滚到渐隐外面。
- 打开以后留在现在的样子，新加一步：
  - 放大模式里还是放大模式，来处不变。
  - 分栏里还是分栏，左边是列表还是拓扑图不变。
  - 首页上，打开成列表加对话的分栏，地址是 `#/slot/<槽位 ID>`。
  - 整页拓扑图上，打开成拓扑图加对话，地址是 `#/topology/slot/<槽位 ID>?chat`。
  - 手机上打开对话页。
- 只跳槽位，不列命令。命令面板照旧只在输入框里（[网页能写规格](web-write.md)）。
- 代码按需加载，第一次按 ⌘K 才下载，看板首屏不变大。

### Alt+↑↓

- Alt+↑ 换到上一个槽位，Alt+↓ 换到下一个。Mac 上是 Option+↑↓。
- 顺序是左边列表或侧栏里从上到下、你眼前看到的那个顺序。鼠标停在列表上、行不挪的时候，也按不挪的顺序。
  - 跳过折起的工作区里藏着的行。露出来的当前那行照算。
  - 跳过已归档。
  - 侧栏收着时，按展开时的顺序。
  - 拓扑图旁边的对话，按列表的顺序。拓扑图没有上下的顺序。
- 到头绕回去：最后一个再往下是第一个。
- 替换当前这一步。
- 只在开着对话时接。分栏、放大模式都接，列表那边、拓扑图那边都接。
- 代价：Mac 输入框里 Option+↑↓ 本来是把光标移到段首、段尾，会被拿走。这一点已知。

### 快捷键什么时候不接

- 输入法正在选字时，⌘K、⌘B、Alt+↑↓ 都不接。
- 输入框的命令面板开着时，↑↓ 和 Alt+↑↓ 都先给面板。
- 以后焦点在[网页终端](web-terminal.md)里时，Ctrl+K、Ctrl+B、Alt+↑↓ 原样给终端：Ctrl+B 是 tmux 的前缀，Ctrl+K 是删到行尾。Mac 上的 ⌘K 照样是跳转框。
- 接了的键，挡掉浏览器自己的动作，例如 Ctrl+K 跳到搜索栏、Firefox 的 Ctrl+B 开书签栏。不接的时候不挡，例如分栏里的 Ctrl+B。

### 焦点

- **打开槽位时光标进输入框。** 点行、跳转框、Alt+↑↓、从首页、拓扑图的“打开槽位”、返回和前进、刷新，都算打开。
  - 只在有鼠标或触控板的设备上（`pointer: fine`）。手机、没接键盘的平板不进，免得弹出键盘。
  - 没有输入框时不抢：挂着提问、TUI 模式、槽位没了。
- **跳转框：** 开着时光标在它自己的输入框里。没选就关掉，光标回原处；选了，光标进新槽位的输入框。
- **收起侧栏时焦点在侧栏里，或者哪儿都不在**（例如拖线收起）：移到输入框。
- **拖中间的线不动焦点。**
- **放大、缩小、展开侧栏：** 焦点和输入框里的字都不动。
- **Esc：** 跳转框开着时只关它。其余照旧：命令面板开着先关面板，回合在跑才停回合。

### 真全屏

- 对话顶栏“⋯”里加“全屏”（lucide `Expand`）。全屏时这一项变成“退出全屏”（`Shrink`）。图标和“放大”的不一样。
- 只在宽屏和中屏、而且浏览器支持时显示（`document.fullscreenEnabled`）。手机上不加。
- 整页进全屏。分栏还是分栏，放大模式还是放大模式，只是地址栏、标签页、任务栏没了。
- 不进地址。刷新就退出全屏，浏览器本来就这样。

Esc 怎么办：

| 浏览器 | 全屏里短按 Esc | 怎么退出全屏 |
|---|---|---|
| 电脑上的 Chrome、Edge | 照旧给 Rhodium：停回合、关信息卡、关跳转框 | 按住 Esc 约 2 秒，浏览器进全屏时会提示；或者点“⋯”里的“退出全屏”；或者 F11 |
| Firefox、Safari | 浏览器拿去退出全屏，Rhodium 收不到 | 按 Esc |

- Chrome、Edge：用浏览器的键盘锁（`navigator.keyboard.lock(["Escape"])`），只锁 Esc。
  - 要求 https，看板经 `tailscale serve` 本来就是；要在点“全屏”的那一下里调用。
  - 按住退出时，按下的那一下也会先到页面。所以全屏而且锁住时，Esc 等松开再算：按下不到半秒就松开，才当成一次 Esc 交给 Rhodium；按住超过半秒不算。
  - 输入法正在选字时的 Esc（`isComposing`，或者 `keyCode` 是 229），原样放过去：不挡、不等、不重发。这一下是取消候选字。重发出去的 Esc 不带选字的记号，输入框会把它当成真的 Esc，停掉在跑的回合。
  - 松开那一下已经不带选字的记号，也不重发：按下时放过去的，松开时不再算。
  - 以后焦点在[网页终端](web-terminal.md)里时，Esc 也按下就给终端，不等松开：终端里的程序要的是马上到的 Esc。按住时浏览器会连着发 Esc，只给终端第一下，后面连发的（`repeat`）丢掉。代价是在终端里按住 Esc 退出全屏时，终端会收到一下 Esc。
  - 平时照旧是按下就算。
- Firefox、Safari：没有键盘锁。Esc 直接退出全屏。个别情况页面也收到了这一下，全屏时丢掉，不交给 Rhodium。退出以后再按 Esc，才是停回合。全屏时要停回合，点输入框的停止键。
- Ctrl+W 不锁。对话页用不上；以后网页终端里真碰到 Ctrl+W 关掉标签页，再在终端里加。

### 未读和跑完提醒怎么做

2026-10-27 定的（#387）。不加表、不加接口、不加 service worker。后端只多写一种事件 `compacted`，见下面。2026-10-31 起 `slot_state` 多带一个 `web` 标记，见“跑完提醒”（#493）。

哪些回合算：

- 页面在事件流里看到一个槽位从 `running` 变成 `idle`。页面打开以后还没收到它的 `slot_state` 时，按列表上它的状态（“运行中”）算。
- 回复发到 IM 的不算，有两种：
  - IM 里开始的回合：结束时 `final_reply` 和它的 `slot_state` 是同一个事务写的，前者在先。
  - agent 在回合里用 `rh send me` 把结果发到了 IM：这种回合没有 `final_reply`，事件流里有它的 `send_me`。网页上开始的、内部回合都一样。
  - 2026-11-06 起，`rh send` 留在网页上的（[产品说明](../product.md) §5.9），`send_me` 带 `web: true`。它不算发到 IM，这个回合照样记未读，最终回复另发到了 IM 也一样：留在网页上的只有网页上看得到。
  - 所以收到这两种事件，这个槽位到回合结束都不算。回合中间的 `running`、`waiting`、`rate_limited` 不清掉它，后面跟着提问、等额度也一样。
- 你的 `/compact` 不算：Claude 上它是单独一个回合，没有回复。
  - 不论从 IM、看板卡片还是网页发的，结束时 router 写一条 `compacted`，和它的 `idle` 同一个事务，在前面。页面当 `final_reply` 看。
  - pi 的 `/compact` 不是回合，槽位不进 `running`。
  - `/model`、`/effort`、`/ultracode` 是控制请求，不是回合；`/new`、`/resume` 由 Rhodium 自己做，槽位不进 `running`。都不用管。
- 不看 `turnEndedAt`：崩溃、从归档恢复也改它。
- 页面打开以前就结束的回合不算。
- 内部回合（`rh send` 唤醒、子槽位汇报、续跑）跑完也算未读：它们的回复也只在网页上。只是不弹跑完提醒，见下面。

未读：

- 算的回合结束时，它的对话不在眼前，就记成未读。在眼前是指：对话开着（分栏、放大模式、拓扑图旁边、手机上的对话页都算，拓扑图的预览不算），而且页面在前台。
- 对话开着、页面在前台时就清掉：打开它的对话，或者页面回到前台。
- 只记在页面的内存里：不同步到别的设备，刷新就没了，不往设备上存。几个标签页各记各的。
- 点是绿色（`--done`），和完成那组一个颜色：蓝色是运行中，琥珀色是需要你。
  - 列表和侧栏那一行：状态字前面一个点，读屏读“未读”。
  - 侧栏收着时的展开按钮：照琥珀点的位置。别的槽位需要你时只亮琥珀点。
  - 折起的工作区、拓扑图、跳转框里不画。
- 不弹轻提示，侧栏也不滚过去。
- 标签页标题：有未读时 `(N) Rhodium`，没有时 `Rhodium`。
- 角标：有 `navigator.setAppBadge` 的地方设成 N，0 时清掉。macOS、Windows 上装成应用时看得到；Linux、安卓没有，什么也不做。

跑完提醒：

- 2026-10-31 改的（#493）。原来算未读的回合跑完都弹，内部回合也弹，弹出来的只有点它才关。Windows 的通知中心里一个网站堆了十几条。
- 只在两种时候弹，页面在后台或窗口没焦点时。对话开着但窗口没焦点，也弹。
  - 你从网页发起的回合，算未读的那种跑完时。
  - 槽位需要你：有提问、审批或确认在等你答。不论回合是谁发起的。
- 弹的是 `new Notification(槽位全名, { body, tag: 槽位 ID })`。
- 别的回合跑完照旧记未读，不弹：子槽位汇报、`rh send` 唤醒、后台任务唤醒、续跑这些内部回合。
- 怎么知道是你从网页发起的：
  - 服务端在 `slot_state` 事件上标 `web`：这次变化前后，槽位在一个网页发起的回合里（`turnChat` 是网页）。所以哪台设备的网页发的都算。
  - 中途等额度、崩溃恢复，回合照旧是你的，它的回复还是答你那句话的，所以跑完也弹。
  - 你在 IM 里插话、在 IM 里答了它的提问，回合就归了 IM（见[网页能写规格](web-write.md)），回复发到 IM，不弹。
  - 你的回合跑完，等它跑完的汇报、`rh send` 紧接着开始下一个回合，槽位不经过 `idle`。页面记着这个槽位在你的回合里，下一个 `idle` 时照样弹。
- 怎么知道需要你：事件流里来了 `ask`，提问、审批、确认都有。为了正文先重取一次 `/api/board`，它在“需要你”那组里才弹。等回合跑完才问的确认请求，这时还不在那组里，不弹。
- 正文：
  - 跑完的：看板上它最近一句话，截到 60 个字，后面加“…”。最近一句话是你说的，就不要正文。
  - 需要你的：“需要你”。
- 看过了，自己关掉：
  - 在这个页面上它的对话开着、页面在前台。和清未读同一个时候。
  - 它的提问、审批或确认答了，不论在哪答的、是不是超时。
  - 它的提问或审批没答就撤了，比如在 IM 里 `/stop`。撤了不写 `ask_answered`，页面看槽位离开 `waiting`。确认请求不让槽位进 `waiting`，撤了不关。
  - 它开始一个你从网页发起的新回合，哪台设备上发的都算。
  - 只关这个页面自己弹的：浏览器只让页面关它自己造的通知。几个标签页都弹过时，留下的那条可能是另一个页面造的：答了、开始新回合，那个页面也会关；在这个页面打开对话，那条留着。
- 同一个槽位只留一条：tag 一样，新的换掉旧的。几个标签页都没在前台时各弹一次，也只剩一条。
- 这个浏览器里另一个 Rhodium 标签页在前台、窗口有焦点，就不弹：你在那边看着它跑完。
  - 标签页之间靠 `localStorage` 里的一个键说谁在前台：拿到焦点时写上自己，失去焦点、转到后台、关掉时擦掉。
  - 在前台时浏览器崩了，键会留着，直到下一个标签页拿到焦点再失去。这期间不弹。
- 点了：页面拿回焦点，打开那个槽位，通知关掉。放大模式里留在放大模式，和跳转框一样（`slotHash`）。
- 每个槽位弹的那条通知，页面在内存里留着，好在看过时关掉。
- 授权：
  - 你第一次从网页发消息时，在点发送或按回车的那一下里问一次。浏览器只在这种时候认真弹授权框。
  - 这台设备记住问过了（`localStorage`）。拒了、关掉了，都不再问。要再开，在浏览器的网站设置里开。
  - 在[设置](#设置)里关了跑完提醒，发消息时也不问。在设置里打开时问过的，也算问过了（2026-10-31，#491）。
  - 问之前先试着构造一条：这时还没授权，浏览器不显示。抛错的是安卓 Chrome 这类，只能经 service worker 发通知，就不问。
  - 存不了东西的页面（例如有的无痕窗口）不问，免得每次都问。
- 没授权、构造抛错（安卓 Chrome），什么都不做。

代码放在新文件 `web/src/unread.ts`：事件流的监听、未读的集合、标题、角标、通知和授权。`main.tsx` 只调用一次它；列表、侧栏、展开按钮读它；发消息时调它问授权。`web` 标记在 `src/daemon.ts` 写 `slot_state` 的地方加（#493）。
